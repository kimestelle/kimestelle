# hi, i'm estelle

I build for how people **think, make, and explore**.

I'm a computer science and computer graphics student at the University of
Pennsylvania, working across graphics, full-stack engineering, and design. I
like projects where the technical system and the way someone experiences it
have to be designed together.

## selected work

- **[Into the Blue](https://github.com/PennSpark/into-the-blue)** — a mobile
  companion for the Penn Museum that helped 180,000+ visitors collect and remix
  artifacts during nine months of deployment.
- **[Internet Atlas](https://github.com/PennSpark/sp25-internet-atlas)** — an
  explorable 3D map of the web built from browsing history, multimodal
  embeddings, and real navigation paths.
- **[Digital Loom](https://github.com/kimestelle/digital-loom)** — turns a
  fabric photograph into a tunable material with PBR extraction, interactive
  cloth simulation, and portable exports.

## graphics & expressive interfaces

- **[Mini Minecraft](https://github.com/kimestelle/mini-minecraft-opengl)** — a
  from-scratch C++/OpenGL renderer with procedural terrain and multithreaded
  chunk generation.
- **[Watercolor Shader](https://github.com/kimestelle/watercolor-drip-shader)** —
  real-time watercolor diffusion using GLSL ping-pong buffers.
- **[Image to Scene](https://github.com/kimestelle/image-to-scene)** — on-device
  monocular depth estimation and WebGPU/WebGL parallax from a single image.
- **[Magnetic Poetry](https://github.com/kimestelle/magnetic-poetry)** — a quiet,
  tactile writing surface with draggable words and high-resolution exports.
